# app_flutter

역전F&C Flutter 대시보드 프로젝트입니다.

## 빠른 실행 (권장)

루트 폴더의 `run_flutter_web.bat`를 더블클릭하면 바로 실행됩니다.

- 실행 대상: Chrome
- 포트: 기본 `3000` (이미 사용 중이면 자동 `3001`)
- 실행 모드: `--release`

브라우저에서 `http://localhost:3000` 또는 `http://localhost:3001`으로 접속하면 됩니다.

## 수동 실행

```bat
cd /d C:\Users\minhyo\yeokjeon\app_flutter
C:\Users\minhyo\.puro\envs\stable\flutter\bin\flutter.bat run -d chrome --release --web-port 3000
```
